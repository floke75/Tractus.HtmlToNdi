## Schema

Each row records:

```
| run_id | timestamp | code_rev | tier | hypothesis | page | fps | bufferDepth | pacingMode |
| pacedInv | bp | adapt | gpu_flags | extra_cef_args | sys_tweaks |
| s.outJitRms | s.outJitPk | s.capFps | s.repeated | s.underruns | s.dropOver |
| r.effFps | r.jitRms | r.jitPk | r.lateCount | r.veryLate |
| sys.cpuPct | sys.pagesSec | sys.diskQ | proc.pgFltsSec |
| pass | notes |
```

Where `s.*` is sender-side telemetry (parsed from `pipeline stats` log lines), `r.*` is receiver-side ground truth (from `Tools/NdiTelemetryReceiver`), and `sys.*` / `proc.*` are peak values during the capture window from PerfMon (Get-Counter polled at 1 Hz). The full per-second CSV is preserved at `Tools/JitterSweep/runs/<run_id>/sysmon.csv` for forensic correlation. Numerical columns to 2 decimal places.
